# JSilva Sonhos — estudo de caso do site publicado

## Minha participação

Otávio desenvolveu o site inteiro, da identidade visual à estrutura em HTML, CSS e JavaScript.

## Maior desafio e abordagem

O maior desafio relatado foi organizar as partes do site com navegação clara, responsividade e uma identidade visual consistente em todas as seções. O trabalho também buscou tornar a experiência mais interativa sem poluir a apresentação.

## Resumo para o portfólio

Um catálogo de kits Pegue e Monte que conecta a escolha da decoração a um pedido de orçamento pelo WhatsApp.

## Necessidade atendida

Permitir que o visitante conheça os temas, entenda as opções de locação e reúna os itens desejados antes de conversar com o atendimento.

## Fluxo da solução publicada

1. Explorar os temas e filtrar o catálogo por categoria.
2. Escolher a opção de locação e adicionar itens ao orçamento.
3. Informar nome, data da festa, local e observações.
4. Abrir o WhatsApp com uma mensagem que reúne os itens, os valores aplicáveis e os dados do pedido.
5. Confirmar disponibilidade e condições de reserva no atendimento.

## Decisões técnicas verificadas no código público

- **HTML, CSS e JavaScript:** estrutura, apresentação e interações da versão pública.
- **Seleção persistente:** o orçamento é salvo em `localStorage`, permitindo recuperar os itens ao recarregar a página no mesmo navegador.
- **Mensagem estruturada:** o JavaScript reúne os dados e usa `encodeURIComponent` para montar o link de conversa no WhatsApp.
- **Preços e opções:** Mini Kits têm valores definidos; outras decorações são apresentadas como orçamento a combinar.
- **Disponibilidade:** a interface pede a data; a confirmação acontece no atendimento, sem prometer uma reserva automática.
