PROJETO 01Site publicado

JSilva Sonhos

Da identidade visual ao catálogo interativo de decoração Pegue e Monte.

Desafio
Organizar a escolha da decoração e reunir os itens do pedido antes de continuar o atendimento pelo WhatsApp.
Solução
Catálogo com filtros, seleção de itens e envio do orçamento pelo WhatsApp. A disponibilidade e a reserva são confirmadas no atendimento.
Funcionalidades
Filtros por categoria, carrinho de orçamento salvo no navegador, dados da festa e mensagem estruturada para o WhatsApp.
Minha participação
Desenvolvi o site inteiro: identidade visual, estrutura em HTML, estilos em CSS e interações em JavaScript.
Ver meu desafio e as decisões do projeto
O maior desafio
Organizar todas as partes com navegação clara e responsiva, mantendo a mesma identidade visual em cada seção.
Minha abordagem
Trabalhei a organização das seções, a adaptação para diferentes telas e a consistência visual. Busquei tornar a experiência mais interativa sem sobrecarregar a apresentação.
Detalhes da implementação
A seleção fica salva no navegador. O formulário reúne os itens e os dados da festa em uma mensagem para continuar o atendimento pelo WhatsApp.
  • HTML
  • CSS
  • JavaScript
  • Design visual
  • WhatsApp

PROJETO 02

Barbearia Prime Club

Escolher um serviço e reservar um horário com regras claras.

Demonstração
Desafio
Organizar serviços, profissionais e horários para evitar que a mesma vaga seja reservada duas vezes.
Solução
Um fluxo de agendamento que consulta disponibilidade e valida a reserva antes de confirmar o atendimento.
Funcionalidades
Serviços, planos, avaliações, escolha de profissional e data, confirmação com código e continuidade pelo WhatsApp.
Ver a decisão técnica do agendamento

Na implementação analisada, a data, o horário e o profissional formam uma chave única no banco. Uma tentativa duplicada recebe resposta HTTP 409 e orienta a escolha de outro horário. A proteção fica no banco, além da lista de horários disponíveis na interface.

  • React
  • TypeScript
  • API HTTP
  • Cloudflare D1
  • Drizzle ORM
